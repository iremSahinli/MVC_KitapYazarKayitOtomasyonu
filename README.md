Kitap - yazar kayıt web otomasyon uygulaması
Bu proje web tabanlı Admin ve Customer rol kontrollü bir kitap yazar kayıt uygulamasıdır. Admin sisteme giriş yaptığında kullanıcı kontrolü yapabilir ve yeni kullanıcı ekleyebilir veya silebilir. Aynı işlemleri yazar ve kitap sayfalarında da gerçekleştirebilir.
Customer sisteme giriş yaptığında sistemde kayıtlı yazar ve kitapları görüntüleyebilir.

- .NET 8 framework
- ASP .NET MVC ile web tabanlı geliştirme sağlandı.
- Entity Framework Core
- Identity yapılandırması ile güvenli rol yönetimi.
- Authorization ve Authentication eklentileri ile yetkilendirme ve giriş işlemlerinin kontrolü sağlandı.
- Area yapılandırması ile aynı uygulama içerisinde farklı rollere göre ilgili sayfa yönlendirmeleri yapıldı.
- SQL server ile veri tip güvenlikli veritabanı yapılandırması eklendi.
- Mapster kütüphanesi ile veri sınıfları arasında dönüşüm işlemleri hızlı ve kolay hale geldi.
- Swagger tabanlı API ile verilerin kontrolü ve güvenliği ayrı bir katmanda kontrol edilerek veritabanı ile doğruadan etkileşimi önlendi.
- SOLID prensipleri ve temiz kod anlayışı ile geliştirildi.
